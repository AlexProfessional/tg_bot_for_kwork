# Telegram Бот-визитка с приемом заявок

Готовый шаблон для малого бизнеса. Бот выдает информацию об услугах и собирает заявки от клиентов, пересылая их напрямую администратору.

## Что умеет:
- Меню с кнопками (Услуги, Цены).
- Прием текстовых заявок от пользователей.
- Мгновенное уведомление администратора о новой заявке (приходит в личные сообщения).

## Технологии:
- Python 3
- `pyTelegramBotAPI` (telebot)
- `python-dotenv` (безопасное хранение токена)
- `Flask` (для поддержания работы сервера на хостинге)
- Хостинг: Render (Deploy via GitHub)

## Как запустить локально:
1. Установите зависимости: `pip install -r requirements.txt`
2. Создайте файл `.env` и добавьте туда `BOT_TOKEN=ваш_токен` и `ADMIN_ID=ваш_id`.
3. Запустите бота: `python bot.py`
